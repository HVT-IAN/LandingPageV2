# Panel de Administración (`admin-front`)

Consulta la documentación completa de instalación, desarrollo, compilación y despliegue en [`docs/admin-front/README.md`](../../../docs/admin-front/README.md).

## Comandos rápidos

```powershell
npm install
npm run codegen   # Genera src/generated/graphql.ts desde docs/graphql/schema.graphql
npm run dev       # Servidor de desarrollo en http://localhost:5173/admin/ (proxy a :8000)
npm run build     # Compila en ../admin-dist
```
